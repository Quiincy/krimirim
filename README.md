# Ресторан «Крим & Рим» — Сайт та Адмін-панель (Next.js + Tailwind CSS + PostgreSQL)

Офіційний вебсайт ресторану кримськотатарської та італійської кухні **«Крим & Рим»** (м. Київ, вул. Братства Тарасівців, 3).

## Можливості
- **Стилістика з оригінального PDF-меню та Google Maps**: Фірмовий ромбовидний логотип `КРИМ & РИМ`, стрічкові заголовки категорій з вирізом, пунктирні лінії цін, кольорові плашки з цитатами для дитячого меню та справжні фото інтер'єру й страв.
- **Повна база даних PostgreSQL (`pg`)**: Автоматична ініціалізація таблиць (`categories`, `menu_items`, `gallery_photos`, `reviews`, `reservations`, `settings`) та первинне наповнення всіма 16 сторінками меню при першому старті.
- **Парсинг та синхронізація відгуків з Google Maps (`/api/reviews/sync`)**: Підтримка прямого парсингу сторінки закладу в Google Картах та офіційного `GOOGLE_PLACES_API_KEY`.
- **Легка адмін-панель (`/admin`)**:
  - Стандартний пароль: `krymirome` (змінюється через `ADMIN_PASSWORD` у `.env`).
  - Редагування, додавання та видалення страв, цін, ваги, описів і фотографій.
  - Завантаження нових зображень напряму з комп'ютера або смартфона.
  - Керування категоріями, фотогалереєю, відгуками Google Maps та онлайн-бронюваннями столиків.

## Запуск локально
1. Встановіть залежності:
   ```bash
   npm install
   ```
2. Налаштуйте `.env.local` (підключення до локального PostgreSQL):
   ```env
   DATABASE_URL="postgresql://quincy@localhost:5432/krimirim"
   ADMIN_PASSWORD="krymirome"
   ```
3. Запустіть сервер розробки:
   ```bash
   npm run dev
   ```
   Сайт доступний за адресою `http://localhost:3000`, адмін-панель — `http://localhost:3000/admin`.

## Деплой на VPS (Docker Compose)
На вашому VPS достатньо виконати:
```bash
docker compose up -d --build
```
Це автоматично підніме PostgreSQL 16, створить таблиці, заповнить початкове меню з 16 сторінок PDF, збереже всі завантажені фото у Docker-томі `uploads_data` і запустить сайт на порту `3000`.
